# Term Documentation

Term is a terminal-native mission control for AI coding agents.

## Quick start

```sh
cargo install --git https://github.com/GrayCodeAI/term
term
```

## Keybindings

See [README](../README.md#keybindings).

## Commands

`:help` inside Term lists all commands. See README for full list.

## Modules

Place executable scripts in `~/.config/term/modules/`. They receive a `status` argument and print one line to stdout.

## Configuration

`~/.config/term/term.toml` — theme, keybindings, accounts.
