# Keybindings

- `q` / `Ctrl+C` — quit
- `Tab` / `←` `→` — switch tabs
- `1`–`6` — jump to tab
- `n` — spawn Claude Code pane
- `x` — close active pane
- `r` — resume last session
- `f` — fork active session
- `[` / `]` — switch active pane
- `a` — jump to next blocked pane
- `:` — command mode
- `=` — delegate mode
- `/` — search mode
- `j` / `k` (Diff, Files tabs) — scroll down / up
- `n` / `p` (Diff tab) — next / previous hunk
- Up / Down — scroll Diff and Files tabs; Up/Down in search selects results
- `z` — zoom pane (full-width, sidebar hidden)
- `{` / `}` — move pane up / down in the sidebar
- `?` — help overlay (Esc closes)
