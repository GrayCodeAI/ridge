# Keybindings

- `q` / `Ctrl+C` — quit
- `Tab` / `←` `→` — switch tabs
- `1`–`6` — jump to tab
- `n` — spawn Claude Code pane
- `x` — close active pane
- `r` — resume last session
- `f` — fork active session
- `[` / `]` — switch active pane
- `a` — jump to next blocked pane
- `:` — command mode
- `=` — delegate mode
- `/` — search mode
