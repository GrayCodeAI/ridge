# Ridge Documentation

Ridge is a terminal-native mission control for AI coding agents.

## Quick start

```sh
cargo install --git https://github.com/GrayCodeAI/ridge
ridge
```

## Keybindings

See [README](../README.md#keybindings).

## Commands

`:help` inside Ridge lists all commands. See README for full list.

## Modules

Place executable scripts in `~/.config/ridge/modules/`. They receive a `status` argument and print one line to stdout.

## Configuration

`~/.config/ridge/ridge.toml` — theme, keybindings, accounts.
